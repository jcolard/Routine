# Routine Hebdo 📅

Application web mobile-first de suivi de routines hebdomadaires, minimaliste, rapide et 100% hors-ligne (PWA).

## ✨ Fonctionnalités
- **Vue semaine épurée** (sans affichage des heures).
- **Découpage des journées** :
  - **Lundi à Jeudi** : 2 parties (*Morning routine*, *Sport routine*)
  - **Vendredi** : 3 parties (*Morning routine*, *Sport routine*, *Friday after routine*)
  - **Weekend** : Repos
- **Cycle interactif 3 états** :
  - **1 clic** : Validé (Vert ✓)
  - **2 clics** : Non fait (Rouge ✕)
  - **3 clics** : Neutre / Réinitialisé
- **Persistance locale** : Sauvegarde automatique dans `localStorage`.
- **Navigation & Suivi** : Progression hebdomadaire dynamique et navigation entre semaines.
- **PWA (Progressive Web App)** : Installable sur Android/iOS et fonctionne entièrement hors-ligne grâce au Service Worker.
